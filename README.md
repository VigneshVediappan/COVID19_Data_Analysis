# COVID-19 Data Analysis

## Aim
To analyze sample COVID-19 case, recovery, and death data using R programming.

## Description
This educational project uses a small sample dataset to demonstrate basic analysis of daily COVID-19 statistics. It calculates totals and identifies the day with the highest number of cases.

## Technologies Used
- R Programming
- Data Frames
- Basic Statistical Functions

## Features
- Displays daily cases
- Calculates total cases
- Calculates total recoveries
- Calculates total deaths
- Finds the day with the highest cases

## How to Run
1. Open `06_COVID19_Data_Analysis.R`.
2. Run the program in RStudio or VS Code.
3. View the output in the console.

## Result
The program successfully performs basic analysis on the sample COVID-19 dataset.
